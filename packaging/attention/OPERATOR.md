# Constellation installed attention

The prepared combined candidate targets Ubuntu 22.04 amd64. Use its source-free
[operator guide](https://github.com/unpingable/unpingable-site/blob/dev/operator-beta/constellation/combined-candidate/README.md) for download verification, exact package installation,
separate enrollment, Workbench, currentness and day-two recovery. It is a neutral
owner-review candidate; BC1 is not tagged or published. Component source alone
does not install the composed product or grant authority.

The evaluator distinguishes informational, attention and page conditions; a page
requires an explicitly eligible/enrolled route. No credentials or routes ship.
Inspect `constellation-attention --build-info`, native evaluator report/state,
service journal and notification outcome. Configure and check before enabling
`constellation-attention.timer`. A failure/refusal is not a healthy pass.

Stop both `constellation-attention.timer` and `.service` before upgrade/removal.
Retain owner configuration, delivery state and notification credential custody
separately. Installation/removal never acknowledges a page automatically.

## Optional notice recurrence candidate

The default configuration remains v1/off. The separate
`attention-recurrence.toml.example` under this documentation directory demonstrates
an opt-in, notice-only operator-beta candidate using local/test routes. Read
[ATTENTION.md](ATTENTION.md#opt-in-notice-recurrence-candidate) for exact bounds,
blocked delivery, report v2 compatibility and explicit state retirement. Do not
replace a live configuration merely by installing this package. Production
promotion requires incident closure and independent qualification.
